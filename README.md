# Car Rental Landing Page

A clean, single-page **car rental landing page** built with React and Create React App. Use it as a starting point for any car rental / vehicle booking website.

## Features

- Landing hero section
- About section
- Premium services (24/7 support, insurance, GPS)
- Cars / vehicle gallery info
- Booking / contact section with social links
- Responsive layout

## Getting Started

```bash
npm install
npm start
```

Runs the app in development mode at [http://localhost:3000](http://localhost:3000).

## Customize

Replace the placeholder content throughout `src/`:

- **Branding / logo** — `src/images/logo.png`
- **Contact phone** — `src/ContactsPage.js`
- **Client testimonials & names** — `src/BookingPage.js`
- **Images** — `src/images/` (cars, clients, icons, social)

## Build

```bash
npm run build
```

Builds the app for production to the `build` folder.
