# Bghit Nsog — Car Rental Landing Page

A clean, single-page landing page for a car rental business. It introduces the service with a hero section, explains what makes the service stand out, shows the available cars, walks visitors through how it works, and closes with a booking and contact section.

## What's included

- Landing hero section
- About section
- Premium services (24/7 support, insurance, GPS)
- Cars / vehicle gallery
- Booking and contact section with social links
- Responsive layout
